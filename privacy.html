Privacy policy

703-assistant is a personal tool used by its single owner on their own computer.

  • It accesses the owner's Google Calendar (scope: calendar) to read and create events on the owner's behalf.
  • Google user data is stored only on the owner's computer, in the owner's own files, and is never transmitted to any third party, sold, or used for advertising.
  • No analytics, no tracking, no server. The OAuth token can be revoked at any time at myaccount.google.com/permissions.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: the repository owner via GitHub, github.com/zoedorable.
